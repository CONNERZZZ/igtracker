วิธีนำข้อมูลออกจาก Instagram

  1. เปิดแอป Instagram ไปที่ การตั้งค่า > ศูนย์บัญชี (Accounts Center)
  2. เลือก ข้อมูลและการอนุญาตของคุณ > ดาวน์โหลดข้อมูลของคุณ
  3. เลือกดาวน์โหลดข้อมูลบางส่วน และเลือกเฉพาะ "ผู้ติดตามและผู้ที่กำลังติดตาม"
  4. เลือกรูปแบบไฟล์ JSON หรือ HTML แล้วกดร้องขอการดาวน์โหลด
  5. เมื่อได้รับไฟล์ ZIP ให้แตกไฟล์ จะพบแฟ้มรายชื่อ นำมาอัปโหลดด้านล่าง

กระบวนการทำงาน (Privacy First)

เว็บไซต์นี้ทำงานด้วย JavaScript ผ่านเบราว์เซอร์ของคุณโดยตรง (Client-Side)

  • ไม่มีการอัปโหลดไฟล์ หรือบันทึกข้อมูลใดๆ ขึ้นสู่เซิร์ฟเวอร์
  • ไม่ต้องล็อกอิน รหัสผ่าน Instagram ของคุณ
  • รับประกันความปลอดภัย ข้อมูลไม่รั่วไหล 100%
  • ประมวลผลดึงรายชื่อได้รวดเร็ว รองรับไฟล์จำนวนมากพร้อมกัน

1. Following (คนที่เราฟอล)

* เลือกเฉพาะไฟล์ following เท่านั้น (ลากคลุมหลายไฟล์ได้)

2. Followers (คนที่ฟอลเรา)

* หากมีหลายไฟล์ (เช่น followers_1, 2...) ให้ลากคลุมอัปโหลดพร้อมกัน
